# ⚽ Football Match Management App

A full-stack football management system to handle teams, players, and matches. Built with **React**, **Go (Gin)**, and **PostgreSQL**.

---

## 🛠 Tech Stack

- **Frontend:** React, Tailwind CSS, Axios  
- **Backend:** Go (Gin Framework)  
- **Database:** PostgreSQL  

---

## 🌟 Features

- ✅ User authentication (JWT)
- ✅ Admin dashboard to manage teams & players
- ✅ Schedule & update matches
- ✅ Live score tracking
- ✅ Player & match statistics
